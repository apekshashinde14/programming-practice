# Number Guessing Game

## Project Overview

The Number Guessing Game is a Python-based command-line application in which the computer generates a random number between 1 and 100, and the player tries to guess it.

The game provides hints to help the player identify the correct number. The player gets a maximum of seven valid attempts to guess the secret number.

## Features

- Generates a random number between 1 and 100.
- Allows a maximum of seven valid attempts.
- Displays "Too High" or "Too Low" hints.
- Displays the correct number when the player loses.
- Shows the total number of attempts when the player wins.
- Validates user input.
- Provides an option to play again.

## Technologies Used

- **Programming Language:** Python
- **Module:** Random
- **Interface:** Command Line Interface (CLI)
- **Concepts:** Variables, Loops, Conditional Statements, Exception Handling, Random Number Generation

## How to Run

1. Make sure Python is installed on your system.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python number_guessing_game.py
```

## Game Rules

1. The computer generates a random number between 1 and 100.
2. Enter your guessed number.
3. The game provides hints:
   - Too High: Your guess is greater than the secret number.
   - Too Low: Your guess is smaller than the secret number.
4. You have seven valid attempts to guess the number.
5. Guess correctly to win the game.
6. Choose whether to play again.
