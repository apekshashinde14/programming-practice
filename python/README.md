# To-Do List CLI Application

## Project Overview

The To-Do List CLI Application is a simple Python-based task management program that allows users to manage their daily tasks through a command-line interface.

Users can add new tasks, view all tasks, mark tasks as completed, and delete tasks. Each task is assigned a unique ID and has a status to track its progress.

This project was developed to practise Python programming concepts such as lists, dictionaries, loops, conditional statements, and exception handling.

## Features

- Add new tasks with a unique ID.
- View all available tasks.
- Mark tasks as completed.
- Delete tasks using their ID.
- Validate user input and handle invalid entries.
- Display appropriate messages when tasks are unavailable or not found.

## Technologies Used

- **Programming Language:** Python
- **Interface:** Command Line Interface (CLI)
- **Concepts:** Lists, Dictionaries, Loops, Conditional Statements, Exception Handling
